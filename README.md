# 🏰 Castle Savior

**황무지에 토대를 다지고, 10번의 공세로부터 성을 지켜라.**

Unity 6로 만든 2D 타워 디펜스 게임입니다. 적들은 정해진 길을 따라 성으로 향하고, 플레이어는 한정된 토대 위에 포탑을 세우고 강화해 성을 지킵니다.

![게임 장면](docs/images/03_battle.png)

## 스토리

성벽 밖은 아직 개간되지 않은 황무지입니다. 단단한 토대 없이는 포탑을 세울 수 없고, 공병대가 쓸 수 있는 자재는 한정되어 있습니다. 수비대장인 당신은 적이 오기 전에 토대를 놓을 자리를 정해야 합니다.

## 핵심 특징

- **토대 시스템**: 포탑은 토대 위에만 세울 수 있습니다. 토대는 최대 6개, 웨이브 사이에만 지을 수 있어 어디에 기반을 다질지가 핵심 전략입니다.
- **진화하는 포탑**: 강화할 때마다 궁수 탑 → 대포 탑 → 번개 탑으로 외형과 투사체가 바뀝니다. 강화는 3웨이브, 7웨이브를 클리어하면 단계별로 열립니다.
- **점점 강해지는 적**: 웨이브마다 적의 체력이 늘어나고(×1.5 ~ ×4.8), 빠른형과 중장갑형이 차례로 합류합니다. 같은 웨이브 안에서 적의 등장 순서는 무작위입니다.
- **예측할 수 있는 난이도**: 적 머리 위 체력바, 상단의 다음 웨이브 체력 배율, 웨이브 시작 알림으로 적이 얼마나 강해지는지 미리 알 수 있습니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| '토대' 버튼을 풀밭으로 드래그 | 토대 건설 (30골드, 웨이브 사이에만) |
| '포탑' 버튼을 빈 토대로 드래그 | 포탑 설치 (60골드) |
| 드래그 중 마우스 오른쪽 버튼 | 설치 취소 |
| 포탑 클릭 | 정보·사거리 표시, 강화·판매 |
| 빈 토대 클릭 | 토대 판매 (웨이브 사이에만) |
| '다음 웨이브' 버튼 | 웨이브 시작 |
| `ESC` | 일시정지 |

## 게임 규칙

| 항목 | 값 |
| --- | --- |
| 웨이브 | 10개 |
| 성 체력 | 7 |
| 시작 골드 / 처치 보상 | 180 / 15 |
| 토대 | 30골드, 최대 6개, 판매 시 15골드 환급 |
| 포탑 | 설치 60, 강화 100 → 160, 판매 시 30골드 환급 |
| 포탑 공격력 | Lv1 1 · Lv2 2 · Lv3 3, 사거리 2.5 |
| 공격 대상 | 사거리 안에서 성까지 남은 경로가 가장 짧은 적 |

| 적 | 기본 체력 | 속도 | 첫 등장 |
| --- | --- | --- | --- |
| 기본형 | 3 | 2.0 | 1웨이브 |
| 빠른형 | 2 | 4.0 | 3웨이브 |
| 중장갑형 | 10 | 1.0 | 5웨이브 |

## 구조

| 스크립트 | 역할 |
| --- | --- |
| `GameManager` | 골드, 성 체력, 게임 상태 관리 (싱글톤) |
| `WaveManager` | 웨이브 데이터대로 적 생성 (코루틴, 체력 배율, 무작위 순서) |
| `Enemy` | 웨이포인트 경로 이동, 피해 처리, 체력바 |
| `Turret` / `Projectile` | 대상 탐색, 레벨별 외형·투사체, 강화 연출 / 대상 추적 |
| `BuildManager` | 토대·포탑 드래그 설치, 설치 규칙 판정, 선택·강화·판매 |
| `HUD` / `UIManager` / `WaveBanner` | 상단 정보 / 일시정지·결과 화면 / 웨이브 알림 |
| `TitleManager` / `TitleWalker` | 시작 화면 |

설계에서 신경 쓴 점

- 웨이브 구성과 포탑 레벨을 **데이터(Serializable 클래스 배열)로 분리**해 코드 수정 없이 밸런스를 조정했습니다.
- **Tilemap 데이터를 설치 규칙에 재사용**했습니다. 길 위인지는 `HasTile`로, 토대와 포탑은 칸 번호 기준 `Dictionary`로 판정합니다.
- 밸런스는 실제 경로를 시간 단위로 시뮬레이션한 결과와 플레이 테스트로 맞췄습니다.
