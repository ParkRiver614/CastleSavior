# Castle Savior
Unity 6로 만든 2D 타워 디펜스 게임입니다.

## 게임 설명
적들이 정해진 길을 따라 성으로 향하고, 플레이어는 골드로 포탑을 설치·강화해
성을 지킵니다. 총 5개 웨이브를 막으면 승리합니다.

## 조작법
- 포탑 버튼을 맵으로 드래그: 포탑 설치 (60골드)
- 포탑 클릭 후 강화 버튼: 강화 (80 / 120골드)
- 다음 웨이브 버튼: 웨이브 시작
- ESC: 일시정지

## 개발 환경
- Unity 6000.3 LTS (6.3)
- C#
